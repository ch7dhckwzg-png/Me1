# Design references

`awesome-design-md/` is [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT, commit `fcc7028`): 84 `DESIGN.md` files, each an analysis of a well-known brand's design system (colours, type, spacing, components, voice), written for AI agents.

Use them as **reference for a direction**, not as something to copy. For example: "take the energy of `design-md/nike/DESIGN.md` but keep our palette and type". Don't reproduce another company's identity on the Catalyze site.

Refresh: `git clone --depth 1 https://github.com/VoltAgent/awesome-design-md` and copy its `design-md/` folder here.
